# S4.2A — Router Lab

基线：main `2835c8f`，目标 DSH `0.2.1-alpha.2` / Node ≥22；基线 91/91。
这是 Turn 级 **观察性记录**，不是随机对照实验。流程 completed 不等于任务成功；人工反馈不等于外部验收。不能由不同模式的样本直接推断质量改善、因果关系或费用节省。

## 入口与采集

原生 Plugins → Adaptive Router → **Router Lab · 路由实验室**。展开、开启「启用实验数据采集」、用原生 SettingsForm 保存；不会自动勾选模型或改变路由策略。默认 false，关闭不清空历史，插件 disabled 也停止采集；需要观察原生基线时保持插件启用并选 MANUAL，不需要 Jev。该偏好从路由修订键中排除，不会触发额外 Jev 分类或打断 Turn 缓存。

只接收根会话完整观测到的 `turn/start` 到 `turn/end`，每 Turn 一条。中途开启、重载、Session 销毁或进程退出导致无法完整观察的 Turn 不冒充完整样本。`tool/call` 按不同 step 汇总；一个 Turn 的多个请求/失败尝试不会变成多个成功样本。

| 数据 | 目标版本实际公开来源 | 限制 |
| --- | --- | --- |
| 路由来源、层级、角色、关系、计划配置、原因、分类耗时 | 现有 `adaptiveRouter` 安全记录 | 保留 Local/Jev/NeoHorse 与不同 confidenceKind，统计置信度不代表准确率；fallbackApplied 表示 Turn 内至少一次已由原生 Header 确认的备用切换，不因后续手动选择抹除 |
| Turn 最终模型/档位 | `session.requestHeader().config`，即最后已提交 Header | 与计划不同会标记 Native override；不代表每次请求来源或 Provider 执行成功 |
| 请求次数 / Usage | `assistant/message`、`assistant/attempt`；Compact stream 最后一个原生 usage chunk | 每次已结束尝试只累计一次；失败前无 Usage 则未知 |
| 用量字段 | Provider 原生 `inputTokens/outputTokens/cacheReadTokens/cacheWriteTokens/reasoningTokens` | inputTokens 为原生 uncached input；不把 TokenMeter 估算当实测；任一尝试缺字段，Turn 对应桶为 null |
| 执行状态与耗时 | `turn/end.reason.kind`、原生事件时间 | completed/error/aborted/interrupted/blocked/max-tokens/forked；仅流程状态 |
| 重试 | `llm/retry-started` | 仅显式观察到时有值，未提供则 null，不猜 0 |
| 人工反馈 | 记录 UUID + 原生记录 revision | 达到预期 / 需要返工 / 无法判断；默认未评分 |

控制状态按 Turn 最后可得决定分组，不冒充全部中间请求的控制次数；后来的手动/原生放行不会擦除此前已知分类事实和自动提议。统计显示覆盖分母；Token 缺失不作为 0，分类延迟只统计有合法分类结果和耗时的 Jev/NeoHorse，缺 URL/凭据等即时放行不冒充远程分类样本。不同路由配置（候选池、档位映射、阈值、锁、分类模型等）由加盐 HMAC 版本标识区分。插件版本从安装包读取，真实构建 commit 不可得则 null；配置版本取 Turn 开始时快照，轮中变化由现有 settings-changed 原因记录，不能用于严格的因果分组。

## 原生存储与上限

使用宿主现有 `storageDomain.open()`；**不自动安装 Storage 服务**。基础 Bundle 已有 JSON backend。无公开服务或 Profile 上下文时明确显示持久化不可用，不退回自建文件/内存假持久化。

Domain：`adaptive_router_lab_<sha256(profileContext.dir)前16位>`，独立于 DSH Session/其他插件，web 与 desktop 分开。只有公开脱敏 Settings 能证明 JSON backend 目录时才展示文件路径；目标默认存储字段非 volatile，Settings 通常不提供该目录，此时 UI 显示 Domain 名称，不冒充已确认文件位置。默认基础 Bundle 明确使用公开 profileContext.home 下 `storages/<domain>.json`，隔离 Host 已实测；自定义 backend 的实际位置由宿主管理；本轮仅验证默认本地 JSON，不承诺自定义 backend 的本地性。需要严格本机存储时应确认宿主将该 Domain 路由到本地 json，插件不擅自更改宿主路由。不猜测 DSH_HOME，不读写私有 Profile lock。

格式：schemaVersion 1，salt 与 records；严格字段白名单。每记录 ≤4096 bytes，最多 5000 条、90 天、总数据 ≤8 MiB（预留 64 KiB 包装空间），最旧先删除。保留策略在打开、写入、刷新、导出时执行，不承诺精确定时擦除。active ≤64 Turn，pending ≤128；溢出显示丢弃计数，模型分布每 Turn 最多16项，每项最多16个档位桶，超过有明确截断标记和面板计数，请求总数仍保留。

事件回调只在内存汇总。Turn 结束后约1秒批量串行写入，不等待磁盘才发 Provider 请求，不处理逐 Token 持久化；大量并发下可能丢弃未落盘记录。原生 JSON backend 负责 temp/fsync/rename 原子替换，POSIX 文件0600；目录权限由宿主维护，Windows ACL 未实测。**文件未加密**。失败显示错误、保留有界待写入批次；不会阻断 Agent。卸载会停止监听、尝试 flush 并关闭 Domain；异常退出仍有未落盘窗口。

清空需要第二次确认，只删除本 Domain，轮换 salt，隔离在途写入/反馈和进行中 Turn，防止旧记录恢复。关闭采集保留数据；卸载默认保留原生存储文件。建议卸载前在面板清空；已卸载时，停止 Host 后只删除已核实属于该 Domain 的本插件文件（自定义 backend 请由宿主管理），不要删除整个 storages 或 Session 历史。

## 隐私与授权

不保存聊天、System Prompt、工具正文/参数、分类请求体、URL、凭据或异常堆栈。Session ID 仅用原生事件内部定位，持久化/导出用带 Profile salt 的 HMAC 代号。代号仍可关联同一 Profile 内的 Turn，应将导出文件视为私人实验元数据。

独立精确路径 `/api/adaptiveRouterLab/{read,feedback,clear,export,checkUpdates}`，使用公共 `connection.fetch.register`（单个 interceptor 留给原生 Gateway），沿用 Connection RPC 信封并再次调用公开 `connection.admit(request)` 获取身份，流式读取请求并限制为4 KiB 在 Host 检查：

1. 经过原生浏览器鉴权，Peer **必须是 `connection.operator` 同一实例**；
2. `allowsRemoteAuthorities === false`，Web Server 明确绑定 loopback；
3. 反馈/清空还要求 `settings.writable === true`。

未知、多用户远程、全地址绑定都拒绝浏览器实验数据访问，不依赖客户端声明的权限/Session ID。不提供任意 Session 查询。该功能当前只支持可信本地单用户 Profile；不是多租户数据服务。原生 Host/Origin 检查继续有效。

最近25条中可修改评分，UUID+revision 防止跨记录误写、重复提交与旧评分覆盖。清空后的迟到反馈拒绝。没有公开适合本版本的 Turn Footer，因此不插入聊天 DOM，也不覆盖原生赞踩。

JSON 包含 schemaVersion、exportedAt、experimentMetadata、records、dataQualitySummary；CSV 使用稳定字段列、UTF-8 BOM/CRLF/标准引号转义，空字段表示未知，防公式注入；嵌套请求分布保留在 JSON，CSV 为 Turn 摘要。浏览器下载完全由用户触发，不上传到第三方。

## 只读更新检查

原生配置底部 **更新与维护**。展开只读取本地信息；点击「检查更新」才请求固定 GitHub 官方仓库 API，npm 来源另查固定 npm 包公开元数据。合并连续点击，5分钟缓存，单请求5秒，响应≤256 KiB，拒绝重定向；无个人 Token、shell、插件安装、Profile 修改或重启。没有后台自动更新。

安装来源使用公开 `pluginManager.listBundles()`，区分 npm、tgz、link、固定SHA、Tag、main；原生 source 的包名前缀也被处理。Profile 名来自公开 profileContext。此版本接口**不公开 lock 解析后的 SHA**，声明固定 SHA 不冒充实际安装 SHA，默认明确「无法准确确定当前安装版本」。不硬编码开发仓库 commit。Release 使用可比较的纯 semver；main 只有真实安装 commit 才可判定新提交或最新；差异可识别仅文档，但不宣称必有功能升级。无正式 Release 与开发分支更新分开，兼容声明不等于运行验证。

手动升级应备份正确的 desktop/web Profile、来源和 lock，完全退出 Host，在外部使用官方管理器安装固定版本，重启检查 active；保留旧 SHA/tgz 和 Profile 备份作回滚。此面板不执行升级命令。安装元数据不明时只给通用安全步骤与 GitHub/Release 链接，不提供猜测的升级命令。
